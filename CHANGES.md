# Changes Summary: Vanilla JavaScript → Vue.js 3

## Quick Comparison

### Before: Vanilla JavaScript
```javascript
// Manual DOM manipulation
const name = document.getElementById('name');
name.value = 'John';

// Manual event listeners
document.querySelectorAll('.spinner-up').forEach(btn => {
    btn.addEventListener('click', function() {
        // Increment logic
    });
});

// Manual DOM generation
function generateEquipmentRows() {
    SETTINGS.equipmentItems.forEach(item => {
        const row = document.createElement('div');
        row.innerHTML = `...`;
        equipmentTable.appendChild(row);
    });
}
```

### After: Vue.js 3
```javascript
// Reactive data
data() {
    return {
        formData: {
            name: 'John'  // Automatically updates UI
        }
    }
}

// Template event handlers
// <button @click="incrementQuantity">

// Declarative rendering
// <div v-for="item in equipmentItems">
```

## Line-by-Line HTML Changes

### Form Element
```diff
- <form id="equipmentForm" novalidate>
+ <form id="equipmentForm" @submit.prevent="handleFormSubmit" novalidate>
```

### Input Fields
```diff
- <input type="text" id="name" name="name">
+ <input type="text" id="name" name="name" v-model="formData.name">
```

### Event Handlers
```diff
- <button type="button" class="spinner-btn spinner-up">
+ <button type="button" @click="incrementTime('pickupHour')" class="spinner-btn spinner-up">
```

### Dynamic Lists
```diff
- <!-- Generated by JavaScript -->
+ <div v-for="item in equipmentItems" :key="item" class="equipment-row">
+     <div class="col-equipment">{{ item }}</div>
+ </div>
```

### Conditional Rendering
```diff
- <div class="feedback hidden"></div>
+ <div class="feedback" :class="{ hidden: !feedback.message }">
+     {{ feedback.message }}
+ </div>
```

### Loading States
```diff
- <button type="submit" id="submitBtn">Wyślij</button>
+ <button type="submit" id="submitBtn" :disabled="isLoading">
+     {{ isLoading ? 'Wysyłanie...' : 'Wyślij' }}
+ </button>
```

## Code Organization Changes

### Before: app.js Structure
```javascript
// 1. Constants
const WEBHOOK_URL = '...';

// 2. DOM References
const form = document.getElementById('equipmentForm');

// 3. Functions (scattered)
function collectFormData() { }
function validateForm() { }
function submitToWebhook() { }

// 4. Event Listeners (at bottom)
form.addEventListener('submit', handleFormSubmit);
```

### After: vue-app.js Structure
```javascript
createApp({
    data() {
        return { /* reactive data */ }
    },
    
    mounted() {
        // Initialization
    },
    
    methods: {
        // All functions organized here
        collectFormData() { },
        validateForm() { },
        submitToWebhook() { }
    }
}).mount('#app');
```
